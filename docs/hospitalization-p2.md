# P2 Hospitalization & Boarding

This slice covers feature IDs `F078-F085` and keeps the rule that every data/API capability is visible in the UI.

## Implemented

- Cage and ward assignment for hospital or boarding stays.
- Treatment sheet tasks with open-task alerting.
- Vital sign snapshots, shift notes and discharge planning fields.
- Owner-visible live status and portal-ready photo update counters.
- API endpoints for listing, summary, create and update flows.
- Web tab with metrics, feature coverage, care alerts, cage board and admission form.
